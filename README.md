# Consumer Complaint Analysis Dashboard (Excel)

## Project Overview
This project analyzes consumer complaint data using Microsoft Excel. The dashboard provides interactive insights into complaint trends, product performance, response time, and customer issues through Pivot Tables, Pivot Charts, KPIs, and Slicers.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Formulas (SUMIFS, COUNTIFS, XLOOKUP, etc.)

## Key KPIs
- Total Complaints
- Timely Response %
- Average Resolution Time
- Complaints by Product
- Complaints by State
- YoY Complaint Growth

## Dashboard Features
- Interactive slicers
- Product-wise analysis
- State-wise analysis
- Monthly trend analysis
- KPI cards
- Dynamic charts

- Excel Dashboard (.xlsx)
